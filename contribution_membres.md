## Membre 2 — Backend / API IA / NoSQL

### Responsabilité principale
Transformer le moteur IA en service exploitable par le front.

### Compétences couvertes
- Paramétrer l’environnement
- Exposer le modèle
- Intégrer API IA
- Accès aux données SQL / NoSQL
- Architecture logicielle

### Tâches concrètes
- Créer le microservice IA, idéalement FastAPI
- Exposer les routes :
  - Recommandation nutrition
  - Recommandation sport
  - Analyse repas
  - Historique recommandations
- Connecter le microservice à la base NoSQL
- Connecter le microservice au backend existant si nécessaire
- Ajouter OpenAPI / Swagger
- Gérer les erreurs :
  - Données manquantes
  - Utilisateur absent
  - Service IA indisponible
  - Fallback
- Ajouter des tests API

### Livrables à produire
- API IA fonctionnelle
- Microservice séparé
- Documentation OpenAPI
- Base NoSQL
- Tests API
- Schéma d’architecture

## Membre 3 — Frontend / UX / Accessibilité

### Responsabilité principale
Créer ou adapter l’interface permettant d’interagir avec les recommandations IA.

### Compétences couvertes
- Développer des interfaces utilisateur
- Analyser les besoins
- Maquetter une application
- Accessibilité
- Visualisation
- Expérience utilisateur

### Tâches concrètes
- Faire le benchmark frontend :
  - React / Vue / Angular
  - Recharts / Chart.js / D3 / Plotly
- Produire les maquettes :
  - Desktop
  - Tablette
  - Mobile
- Créer les pages :
  - Recommandation nutrition
  - Recommandation sport
  - Résultats IA
  - Historique
  - Filtres préférences
- Intégrer l’API IA :
  - Formulaire de requête
  - Affichage du résultat
  - État loading
  - Erreur
  - Fallback
- Améliorer l’accessibilité :
  - Contrastes
  - Labels
  - Navigation clavier
  - Messages d’erreur clairs
  - Responsive
- Préparer les captures pour le rapport

### Livrables à produire
- Benchmark frontend
- Maquettes responsive
- Interface fonctionnelle
- Captures
- Note accessibilité
- Tests front critiques
